# Keplar One repository audit, October 2026

Audited 2026-10-18 against `main` at `287a5b1` (PR #80, live on keplar.one). This is Phase 0 of the master production directive. Every statement points at a file in this repository. Where something is labelled "partial" or "missing", that comes from reading the code, not from assuming. Nothing in this audit was checked against production data, live provider accounts or real payments.

Scale at audit time: 292 API route handlers (`src/app/api/**/route.ts`), 143 pages (`src/app/**/page.tsx`), 411 unit test files (`tests/*.test.ts`, about 3,100 tests), 49 Playwright specs (`e2e/*.e2e.ts`).

## 5. Technical debt

- **Very large modules.** `src/lib/orchestration/orchestrator.ts` is about 870 lines in one generator, and `src/lib/business/agents.ts` is 553. New behaviour is safest as pure modules called from them, which is how milestone 1 is built.
- **Three audit logs and several status unions** (see §3) that will need unifying before a shared task-state machine.
- **Runtime DDL** (R7) scattered across modules, with no single view of the schema.
- **Windows deploys**: `scripts/deploy.mjs` assumes Linux paths (`docs/security-progress.md`).
- **Catalog freshness**: prices are a dated snapshot. The `TODO(founder approval)` cost estimates are in `compute.ts`.
- **CRLF working tree on Windows** (`core.autocrlf=true`). Harmless, but scripted edits must normalise line endings.

## 7. First executable milestone

**Server citation check for Deep Research.** Each `[n]` left after `linkCitations` is compared with the text the search returned for page n. A citation whose page has real text and shares almost nothing with the sentence (no number, under 12% of content words) is removed, and the sentence is kept. Results ride on the answer as `research.checked` (`by: "server"`) and appear in the existing "Citation check" disclosure, with counts in the report header.

- Code: `src/lib/research/citation-check.ts` (pure), `src/lib/orchestration/research.ts` (keeps up to 4,000 characters of each page's returned text server-side, never streamed), `src/lib/orchestration/orchestrator.ts` (runs the check), `src/lib/orchestration/types.ts` (`CitationCheck`), `src/components/app-ui/research/Research.tsx` and `KeplarTurn.tsx` (display).
- Tests: `tests/citation-check.test.ts` (supported, mismatched and removed, fabricated, conflicting number, partial / only together, page without text, code and links untouched, cap and ordering, evidence kept server-side) and a full-pipeline case in `tests/deep-research.test.ts`.
- Limits, stated in the UI: words and numbers are compared, not meaning. A paraphrase can read as "partly supported". Only the search's returned text is evidence, never the reading model's notes.
- No database, auth, payment or deployment change.
